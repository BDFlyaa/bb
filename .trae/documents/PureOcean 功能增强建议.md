# PureOcean 功能增强建议

基于对整个项目的完整审查，以下是按模块分类的功能增强建议，按 **实用性** 和 **实现难度** 排序。

------

## 🔔 一、通知中心（全新模块）

**现状**：系统缺少统一的通知机制，用户无法感知审核结果、订单状态变更等重要事件。

**建议**：在 `MainLayout` 顶栏添加通知铃铛图标 + 下拉面板。

| 通知类型          | 触发场景                 |
| :---------------- | :----------------------- |
| 打卡审核通过/驳回 | 管理员审核后推送         |
| 订单发货          | 管理员标记发货后推送     |
| 积分变动          | 任务完成、兑换扣除时推送 |
| 活动提醒          | 参加的社区活动即将开始   |

TIP

实现方式：新建 `Notification` 模型 + `/api/notifications` 路由，前端轮询或使用 SSE。

------

## 📊 二、数据统计增强（Statistics）

**现状**：管理员大屏有分类占比和7日趋势，但缺乏导出、对比等高级分析能力。

| #    | 功能             | 说明                        | 难度 |
| :--- | :--------------- | :-------------------------- | :--- |
| 1    | **数据导出**     | 管理员可导出 CSV/Excel 报表 | ⭐⭐   |
| 2    | **月度对比**     | 本月 vs 上月同比环比分析    | ⭐⭐   |
| 3    | **站点热力排行** | 各站点回收量排名图          | ⭐⭐   |

------

## 🗺️ 三、回收地图增强（Map）

**现状**：地图有站点标注、申报、报错功能，但缺少导航和搜索。

| #    | 功能             | 说明                               | 难度 |
| :--- | :--------------- | :--------------------------------- | :--- |
| 1    | **站点搜索**     | 按名称/地址搜索过滤站点            | ⭐    |
| 2    | **路线导航**     | 点击站点可唤起高德导航             | ⭐⭐   |
| 3    | **站点详情弹窗** | 显示站点照片、营业时间、容量进度条 | ⭐⭐   |

------

## 📋 四、打卡签到增强（Checkin）

**现状**：支持扫码打卡和 AI 拍照识别，有完整的审核流程。

| #    | 功能             | 说明                                       | 难度 |
| :--- | :--------------- | :----------------------------------------- | :--- |
| 1    | **打卡日历**     | 用日历视图展示每月打卡天数和连续打卡streak | ⭐⭐   |
| 2    | **连续打卡奖励** | 连续3/7/14天打卡额外奖励积分               | ⭐⭐   |
| 3    | **批量审核**     | 管理员一键批量通过/驳回待审核记录          | ⭐⭐   |

------

## 🛒 五、积分商城增强（Mall）

**现状**：有完整的商品展示、兑换、订单管理功能。

| #    | 功能                | 说明                                 | 难度 |
| :--- | :------------------ | :----------------------------------- | :--- |
| 1    | **我的订单页**      | 志愿者端查看自己的兑换订单和物流状态 | ⭐⭐   |
| 2    | **积分明细**        | 积分收入/支出的详细流水记录          | ⭐⭐   |
| 3    | **商品收藏/心愿单** | 积分不够时可以先收藏                 | ⭐⭐   |

------

## 🌱 六、社区增强（Community）

**现状**：有动态流（发帖/评论/点赞）、任务系统、管理员禁言。

| #    | 功能             | 说明                       | 难度 |
| :--- | :--------------- | :------------------------- | :--- |
| 1    | **活动签到**     | 线下活动到场后可签到确认   | ⭐⭐   |
| 2    | **帖子图片轮播** | 支持多图上传，左右滑动查看 | ⭐⭐   |
| 3    | **@提及用户**    | 在评论中@其他志愿者        | ⭐⭐⭐  |

------

## 🔗 七、区块链溯源增强（Traceability）

**现状**：支持批次号查询和管理员记录表，但展示比较简单。

| #    | 功能                | 说明                                               | 难度 |
| :--- | :------------------ | :------------------------------------------------- | :--- |
| 1    | **溯源时间轴**      | 用可视化时间轴展示物资流转全过程（回收→分拣→再生） | ⭐⭐   |
| 2    | **溯源证书**        | 生成可分享的电子环保证书/海报                      | ⭐⭐⭐  |
| 3    | **管理员搜索/筛选** | 按日期、站点、状态筛选溯源记录                     | ⭐    |

------

## 👤 八、用户与认证增强（Auth）

**现状**：基础的用户名+邮箱+密码注册/登录，JWT 认证。

| #    | 功能             | 说明                     | 难度 |
| :--- | :--------------- | :----------------------- | :--- |
| 1    | **个人资料编辑** | 修改头像、昵称、个人简介 | ⭐⭐   |
| 2    | **修改密码**     | 已登录用户修改密码       | ⭐    |
| 3    | **忘记密码**     | 通过邮箱验链重置密码     | ⭐⭐⭐  |

------

## ⭐ 推荐优先实现（最具价值 + 可行性高）

| 优先级 | 功能                        | 理由                               |
| :----- | :-------------------------- | :--------------------------------- |
| 🥇      | **通知中心**                | 连接各模块，提升用户体验闭环       |
| 🥈      | **打卡日历 + 连续打卡奖励** | 增强用户粘性，鼓励持续参与         |
| 🥉      | **我的订单页 + 积分明细**   | 商城体验完整化，用户能追踪积分去向 |
| 4      | **溯源时间轴**              | 核心差异化功能，体现区块链理念     |
| 5      | **个人资料编辑**            | 基础用户体验补全                   |
